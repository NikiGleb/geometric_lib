# Документация проекта «Math formulas»

## Общее описание решения

Проект представляет собой набор Python-модулей для вычисления площади и периметра
геометрических фигур. Каждая фигура вынесена в отдельный модуль, внутри
которого объявлены две функции с одинаковыми именами: `area` — площадь и
`perimeter` — периметр.

Структура проекта:

```
.
├── circle.py        — окружность
├── rectangle.py     — прямоугольник
├── square.py        — квадрат
├── triangle.py      — треугольник
└── docs/
    └── README.md    — документация по проекту
```

## Описание функций

### Модуль `circle.py`

#### `area(r)`

Возвращает площадь круга радиуса `r`, вычисленную по формуле `S = πR²`.

| Параметр | Тип   | Описание     |
| -------- | ----- | ------------ |
| `r`      | float | радиус круга |

Возвращаемое значение: `float` — площадь круга.

```python
>>> circle.area(2)
12.566370614359172
```

#### `perimeter(r)`

Возвращает периметр окружности радиуса `r`, вычисленную по формуле `P = 2πR`.

| Параметр | Тип   | Описание          |
| -------- | ----- | ----------------- |
| `r`      | float | радиус окружности |

Возвращаемое значение: `float` — периметр окружности.

```python
>>> circle.perimeter(2)
12.566370614359172
```

### Модуль `rectangle.py`

#### `area(a, b)`

Возвращает площадь прямоугольника со сторонами `a` и `b`, вычисленную по формуле `S = ab`.

| Параметр | Тип   | Описание             |
| -------- | ----- | -------------------- |
| `a`      | float | длина первой стороны |
| `b`      | float | длина второй стороны |

Возвращаемое значение: `float` — площадь прямоугольника.

```python
>>> rectangle.area(3, 4)
12
```

#### `perimeter(a, b)`

Возвращает периметр прямоугольника со сторонами `a` и `b`, вычисленный по формуле `P = 2 * (a + b)`.

| Параметр | Тип   | Описание             |
| -------- | ----- | -------------------- |
| `a`      | float | длина первой стороны |
| `b`      | float | длина второй стороны |

Возвращаемое значение: `float` — периметр прямоугольника.

```python
>>> rectangle.perimeter(3, 4)
14
```

### Модуль `square.py`

#### `area(a)`

Возвращает площадь квадрата со стороной `a`, вычисленную по формуле `S = a²`.

| Параметр | Тип   | Описание               |
| -------- | ----- | ---------------------- |
| `a`      | float | длина стороны квадрата |

Возвращаемое значение: `float` — площадь квадрата.

```python
>>> square.area(5)
25
```

#### `perimeter(a)`

Возвращает периметр квадрата со стороной `a`, вычисленный по формуле `P = 4a`.

| Параметр | Тип   | Описание               |
| -------- | ----- | ---------------------- |
| `a`      | float | длина стороны квадрата |

Возвращаемое значение: `float` — периметр квадрата.

```python
>>> square.perimeter(5)
20
```

### Модуль `triangle.py`

#### `area(a, h)`

Возвращает площадь треугольника с основанием `a` и высотой `h`, проведённой к
этому основанию, вычисленную по формуле `S = ah / 2`.

| Параметр | Тип   | Описание                                  |
| -------- | ----- | ----------------------------------------- |
| `a`      | float | длина основания треугольника              |
| `h`      | float | длина высоты, проведённой к основанию `a` |

Возвращаемое значение: `float` — площадь треугольника.

```python
>>> triangle.area(6, 4)
12.0
```

#### `perimeter(a, b, c)`

Возвращает периметр треугольника со сторонами `a`, `b` и `c`, вычисленный по
формуле `P = a + b + c`.

| Параметр | Тип   | Описание              |
| -------- | ----- | --------------------- |
| `a`      | float | длина первой стороны  |
| `b`      | float | длина второй стороны  |
| `c`      | float | длина третьей стороны |

Возвращаемое значение: `float` — периметр треугольника.

```python
>>> triangle.perimeter(3, 4, 5)
12
```
